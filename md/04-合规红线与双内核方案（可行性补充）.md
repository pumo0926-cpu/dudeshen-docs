# 合规红线与双内核方案：对标 Achieve3000 做初高中语文+英语阅读产品的可行性补充

> 调研日期：2026-09-13

## 结论先行

**直接照搬不可行；改造后可行，但必须拆成两个产品内核，并且英语先行、语文跟进。**

三条判断：

1. **合规上不是"能不能做"的问题，是"做成什么形态"的问题。** 语文和外语都被明确列为学科类；学科培训类教育 App 的提供者必须是"取得省级办学许可 + 民政登记的**非营利法人**"，且该定义明确覆盖**义务教育阶段和高中学生**。新主体拿这个牌照的路径实质上已经关闭。**唯一活路是做工具 / 内容 / 测评，坚决不做"培训服务"。** Achieve3000 恰好天然长在这条安全线内侧——它没有老师、没有课时、没有课程班期。这是它可被对标的最大幸运。
2. **中文分级这条路走不通，英语分级走得通。** 英文有 Lexile 这把成熟标尺；中文没有公认统一标尺，且初高中语文的难度根本不在字词层面，而在思想深度与文化背景。**照搬"12 级难度改写"到语文上，是把一个错误的模型套到一门错误的学科上。**
3. **家长付费意愿是真实存在的**（AI 学习机 2024 年卖了 592.3 万台、190.6 亿元，均价 3164 元），但**这笔钱正在被硬件和免费 AI 分走**，纯软件订阅要拿到它，必须给出硬件和大模型都给不了的东西——内容、习惯和同龄人。

# 第一部分：可行性判断

## 一、合规：三道门，一条安全通道

### 门 1｜学科类身份（最硬）

- 国家规定中，**道德与法治、语文、历史、地理、数学、外语（英语/日语/俄语）、物理、化学、生物按学科类管理**——语文和英语两科全在名单里，没有任何解释空间。
- 教育部对学科培训类教育 App 的定义：*含有语文、外语等学科内容，并**面向义务教育阶段和高中学生提供以上学科培训服务**的教育移动应用*；提供者**必须是取得省级教育行政部门办学许可、经民政部门登记的非营利法人**。
- 注意"高中"也被明确纳入——**别指望用"我们只做高中"绕开**。

**安全通道在"培训服务"这四个字上。** 判定的实质分界线不是学科内容，而是有没有构成"教学/培训"：

| ❌ 触线（构成培训服务） | ✅ 安全区（工具/内容/测评） |
|---|---|
| 教师直播 / 录播授课 | 无真人授课，只有文本与题目 |
| 课程体系、班期、开课时间表 | 内容按主题/难度组织，随时进出 |
| 按课时售卖、报名、退费 | 按时长订阅（年卡/月卡） |
| "同步教材第 X 单元"式提分包装 | 阅读能力/素养定位，不绑教材进度 |
| 老师带练、作业批改服务 | 系统自动判分 + AI 反馈 |

> **Achieve3000 的五步流程整套落在右列。** 这正是它值得对标的核心原因——它是一个没有老师的教学产品。

### 门 2｜教育 App 备案

- 面向学生/家长、以学习为主要场景的 App 需在教育部备案平台（app.eduyun.cn）完成**提供者备案 + 应用备案**，并逐省落地（如北京有实施细则）。通用工具不需要，但"教育特化版本"需要——一个初高中阅读 App 必然属于需要备案的范畴。
- **一个常被误读的点**：2019 年八部门意见中"不得向学生及家长收取任何费用、不得植入商业广告和游戏"，约束的是**学校统一要求使用的教育 App**。**家长自愿选择购买的市场化 App 不在此列**——这正是纯 C 端路线在合规上比进校路线更宽松的地方。
- 但"不得植入商业广告和游戏"的价值导向仍会被参照审查，**产品内不要出现广告变现和游戏化抽奖式设计**。

### 门 3｜未成年人模式

- 《未成年人网络保护条例》2024-01-01 施行；《移动互联网未成年人模式建设指南》2024-11 发布。
- 硬性节奏约束：**16 岁以下默认每日使用不超过 1 小时；16–18 岁不超过 2 小时。**
- **这看起来是限制，实际是设计礼物**：它替你否决了"沉浸式长时长"的产品方向，并给了一个天然的产品节拍——**单次 10–15 分钟、每日一篇**，恰好就是 Achieve3000 的剂量结构。

### 附加门｜内容版权（最容易被低估）

- Achieve3000 二十五年最硬的资产是**它自己采编原创的文章库**——所以它能随意改写成 12 个难度版本，不需要向任何人付版权费。
- 中国团队若走"搬运外刊 + 名著原文 + 教材课文"的路，同时踩三颗雷：外刊版权、出版社版权、统编教材使用许可。
- **结论：内容必须自采编、版权自持。** 好消息是，用大模型生成多难度版本的成本已经降到 2001 年的千分之一——**这是今天做这件事唯一比 Achieve3000 强的地方。** 但必须有人工终审，事实性错误在教育产品里是致命的。

## 二、需求：真实，但两科的真实性不一样

### 语文侧：需求在变强 ✅

- 新课标把"整本书阅读"从教学点缀变成必修任务；教育部《中小学生阅读指导目录》明确了初中 100 种、高中 90 种书目。
- 2026 年高考语文命题变化：**主观题比例提高、选择题减少、增强开放性与综合性、增加古诗文比重、强调情境化设计**；作文从"坐而论道"转向"起而行之"。
- **含义：语文正在从"能背"转向"能读懂、能想清、能写出来"——这恰恰是刷题解决不了、而阅读产品能解决的部分。** 这是十年一遇的需求结构变化。

### 英语侧：需求真实但有政策尾部风险 ⚠️

- 2026 两会有政协委员建议**高考英语由 150 分降至 100 分、一年两考取最高分**（仅为建议，非政策）。同时农村考生英语平均分低于城市考生约 20 分的结构性差距，是这类建议的长期推力。
- 但 2026 年的实际调整是**改题型不是砍学科**：听力第一节由播一遍改为两遍、完形填空提高难度但降低分值占比、作文新增 10 分应用文。
- **含义：英语作为"实用能力"的定位在强化，作为"选拔工具"的权重存在长期下行风险。** 做英语阅读产品要押"能力"而不是押"提分"，才能穿越政策周期。

### 付费能力：有钱，但钱正在流向别处

| 参照物 | 价格 | 说明 |
|---|---|---|
| AI 学习机（2024） | **592.3 万台 / 190.6 亿元**，均价 **3164 元** | 2000–3999 元价位占销量 50%+；作业帮约 30%、学而思约 13%、科大讯飞约 12% |
| 学而思伴读书房（人文创作系统课） | 约 **1600 元/期** | 直播+录播课形态 |
| 豆神·语文本 | **4999 元** | 墨水屏学习硬件 |
| Achieve3000 中国团购 | **¥468 / 年** | 单人账号，渠道自加中文周报 |

**关键判断：家长愿意为"孩子的语文英语"一次性掏三四千买硬件，却很难为一个 App 掏 1000 元。** 纯软件的定价天花板现实地落在 **300–800 元/年**。

## 三、最大的技术分歧：中文没有 Lexile，而且不该有

| | 英语 | 语文 |
|---|---|---|
| 现成标尺 | Lexile 成熟（4 个维度：Structure / Decoding / Syntactic / Semantic），全球通用 | **无公认统一标尺**。亲近母语的中文分级标准只覆盖 6–12 岁；考拉阅读自研 ER 体系但公司已淡出 C 端 |
| 难度来源 | 词汇 + 句法复杂度为主 → **可量化、可自动改写** | 思想深度、文化背景、言外之意、审美判断 → **量化即失真** |
| 结论 | ✅ 分级模型可直接对标 | ❌ 分级模型不成立，**必须换成"深度阶梯"** |

**这一条决定了产品架构**：语文和英语不能共用一个内核，只能共用一个习惯层（每日节奏、输出机制、成长档案）。

> 把《背影》改写成 12 个难度版本是荒谬的；但把《背影》拆成"读懂发生了什么 → 读懂作者怎么写的 → 读懂他为什么这样写"三层，是成立的。**英语解决"读不懂"，语文解决"读不深"。**

---

## 四、前车之鉴：考拉阅读

- 2016 年成立，**明确对标 Achieve3000**，自研 ER 中文分级阅读标准，2018 年拿到 GGV 纪源资本 + XVC 领投的 **2000 万美元 B 轮**。
- 结局：转向进校 B 端，C 端声量基本消失。
- **它的失败不是执行问题，是本文前三节的合集**：中文分级标尺自建成本极高且难获公信、C 端动机机制缺失、双减后学科类身份受限。**任何人重做这件事，都要先说清楚自己凭什么不重蹈这条路。**

# 第二部分：纯 C 端如何改良

> ⚠️ 本部分与 `03-纯C端阅读产品改良方案.md` 存在重叠。若已读 `03`，本部分只需看四处增量：
> **支点 1**（家长端与孩子端要用两套语言，且家长端只做"看得见"不做"管得着"）、
> **支点 3**（语文与英语双内核、共用习惯层）、
> **支点 4**（北极星是完成率而非能力值，配 Achieve3000 的 8% 达标率作参照）、
> **第七节**（免费 AI 与高考英语降权两个外部风险）。其余可跳过。

> 核心命题：**Achieve3000 的动力机制长在学校里。** 去掉进校，就等于抽走了老师布置、计入成绩、使用率报表这三根支柱。**产品必须自己长出骨头。**
>
> 提醒一个数字：在学校强制、老师布置、计入成绩的最强约束下，Achieve3000 的年度剂量达标率仍只有 **8%**，22% 的学生一篇未读。**纯 C 端要做的第一件事不是提高效果，是提高完成率。**

## 支点 1｜把"家长付费、孩子使用"从矛盾变成结构

Achieve3000 把家长当旁观者（250 个账号白送也没人用）。纯 C 端不能这样——**家长是第一付费用户，孩子是第一使用用户，两端都必须被满足，且要用两套语言。**

| | 孩子端 | 家长端 |
|---|---|---|
| 只谈 | 内容、观点、成就、同龄人 | 证据、趋势、确定性 |
| 绝不出现 | 家长在监视你 | 今天孩子偷懒了（指控式话术） |
| 核心交付 | "这篇有意思，我有话说" | "我能向自己交代" |
| 形式 | 每日一篇 + 输出 + 反馈 | **每周一封周报**（中国渠道商自发为 Achieve3000 补做中文周报，证明这是被官方长期忽略的真需求） |

**红线：家长端只做"看得见"，不做"管得着"。** 一旦加入强制提醒、进度催办、实时监控，孩子会立刻把产品识别为家长的延伸，然后放弃它——这是 Achieve3000 在美国被学生当作"学校的工具"而集体反抗的同一机制。

## 支点 2｜动机内建：把 Achieve3000 外包给老师的那部分，自己做

这是纯 C 端改良的**全部重点**。四件事：

### 2.1 内容时效性是生死线
Achieve3000 最集中的差评是"文章是 2004 年的"——一个自称时事阅读的产品，内容陈旧等于自毁根基。**每日更新、当周热点，是 C 端产品不可谈判的底线。**

### 2.2 选题要有"可说性"
初高中生不缺信息，缺的是**值得表达观点的话题**。选题标准应该是：*读完之后，他有没有话想说？* 争议性、现实感、与自身处境相关——而不是"科普知识点"。

### 2.3 把"读后投票"从私下动作变成社交动作
Achieve3000 有一个极聪明但被浪费的设计：**读前投票 + 读后投票的观点对比**。它只让学生自己看见。
**改良：让观点可发布、可看见同龄人的分布、可互相回应。** 一个 15 岁的孩子会为了"我的看法被人看见"而读完一篇文章——这个动力比任何分数都强，而且是学校产品做不到的。（需配套内容审核与实名合规，属于必要成本。）

### 2.4 剂量设计要向未成年人模式看齐
**单次 10–15 分钟、每日一篇、可断可续。** 不做长时长沉浸，不做"闯关连续包月"式的成瘾设计（也不合规）。**要让"今天读了"这件事本身容易发生，而不是让"读得多"这件事有奖励。**

## 支点 3｜双内核，共用一个习惯层

```
        ┌──────────── 习惯层（共用）────────────┐
        │  每日一篇 · 观点输出 · 成长档案 · 周报  │
        └───────┬────────────────────┬──────────┘
                │                    │
      ┌─────────▼────────┐  ┌────────▼─────────┐
      │   英语内核        │  │   语文内核        │
      │  分级 · 难度匹配   │  │  深度阶梯 · 三层读 │
      │  解决"读不懂"     │  │  解决"读不深"     │
      │  可量化能力值      │  │  作品化输出为主    │
      └──────────────────┘  └──────────────────┘
```

- **英语内核**：照抄 Achieve3000 的分层逻辑（同一话题多难度版本 + 首答正确率驱动升降级），这是它被验证过的部分，且用 AI 实现成本极低。
- **语文内核**：不做难度分级，做**同一文本的三层解读阶梯**——读懂发生了什么 → 读懂作者怎么写 → 读懂为什么这样写。输出形式从选择题转向**短评、批注、辩论**，因为语文的能力本来就不该用选择题验收（这也正是 2026 高考语文主观题比例提高的方向）。

## 支点 4｜北极星指标：完成率，不是能力值

| | Achieve3000 | 我们 |
|---|---|---|
| 对外宣传 | 蓝思值增长 3.5 倍 | 年度剂量达标率 |
| 实际达标 | **8%**（80 篇/年） | 目标 **≥40%** |
| 隐含逻辑 | 效果由剂量决定，但剂量没人管 | **先解决"读下去"，再谈"读得好"** |

一条 40% 的完成率曲线，商业价值远大于一条漂亮的能力值曲线——因为**续费由前者决定**。

## 支点 5｜内容自采编，版权自持

- 这是 Achieve3000 二十五年积累下来最不可复制的资产，也是唯一必须硬投入的地方。
- 建议结构：**自采编原创（主力）+ 公版经典（语文）+ 少量正规授权引进**。
- AI 负责多版本改写与初筛，**人工负责选题与终审**。事实错误、价值观偏差在这个品类里是一票否决项。

## 六、商业模式建议

- **定价**：**399–699 元/年**。参照系：AI 学习机均价 3164 元（一次性）、学而思伴读书房 1600 元/期、Achieve3000 中国团购 468 元/年。定在 500 元附近是家长"不用商量就能决定"的心理区间。
- **绝不做**：课时包、班期、报名制、退费制——这些是学科培训的形式特征，是合规上的自杀动作。
- **硬件**：先别做。学习机赛道已由作业帮/学而思/讯飞占据 55%+ 份额，且是渠道和供应链的战争。**先用软件验证留存曲线，硬件是留存被证明之后的放大器，不是获客手段。**

## 七、最大的两个风险

### 风险 1｜免费 AI 正在把"理解"变成免费商品
豆包爱学、夸克等在 2026 开学季直接发放学生免费会员。**任何以"AI 帮你读懂/翻译/精读"为卖点的产品，价值都会在 12 个月内归零。**
→ **付费理由必须建立在 AI 给不了的东西上：持续更新的原创内容、被设计出来的习惯、以及同龄人的存在。**

### 风险 2｜高考英语权重下行
建议虽未成为政策，但方向性信号已连续多年出现。
→ **英语侧的价值主张要押"能力与视野"，不能押"提分"。** 押提分的产品会随一纸文件归零，押能力的不会。

## 八、12 个月最小验证路径

| 阶段 | 做什么 | 验收标准（只看这个） |
|---|---|---|
| M1–M3 | 英语内核 MVP：每日一篇原创时事 + 3 难度版本 + 首答判分 + 观点输出 | **次月留存 ≥35%**，单次时长 10–15 分钟 |
| M4–M6 | 加家长周报 + 同龄观点广场 + 成长档案 | **付费转化 ≥5%**，家长周报打开率 ≥50% |
| M7–M9 | 语文内核灰度：经典文本三层阶梯 + 短评输出 | 语文模块周活占比 ≥30% |
| M10–M12 | 全量 + 年卡续费验证 | **年度剂量达标率 ≥40%**、续费率 ≥40% |

**任何一个阶段的验收标准都不是"能力值增长"。** Achieve3000 已经用 25 年和 7 亿美元证明：能力值增长是真的，但它在真实世界里被完成率死死卡住。
