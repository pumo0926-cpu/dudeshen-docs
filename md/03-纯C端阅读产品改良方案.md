# 纯 C 端初高中阅读产品改良方案

日期：2026-09-13。承接项目现有竞品分析与可行性评估。本方案按最新要求，排除学校采购、教师布置、班级实施及学校导流；家庭自主购买，学生在家使用。以下产品机制、定价和经营数字均为待验证建议，未开展真实访谈、产品实验或收费。

**建议定位：面向中学生的主题阅读会员，让孩子每周花三次、每次约 12—15 分钟，读懂一个感兴趣的问题，并逐步学会用文本证据表达观点。家长购买的是适合孩子的持续阅读安排和可见的学习收获。**

C 端改良的关键是同时满足两个人：孩子决定是否继续读，家长决定是否继续买。内容吸引第一次打开，合适的难度和反馈帮助完成，作品与独立阅读表现支持续费。这条链条中的任何一环，都不能仅靠积分补足。

## 1. 先选一个能服务好的家庭群体

首批建议聚焦初一、初二：有基本英语阅读基础，短文能读，但遇到陌生主题、长句或推断问题容易放弃；家长重视阅读，愿意安排时间，但不愿每天批改、讲解。优先验证有固定设备和每周三次阅读时间的家庭。

不要只按校内考试分数筛选，用两篇不同题材的短文试读，观察理解、求助和兴趣。首批并非完全自驱的优等生，也不承诺能替代零基础教学或密集补差。

| 家庭类型 | 初期适配判断 | 产品取舍 |
| --- | --- | --- |
| 有基础、读得少、缺少合适材料 | 优先 | 帮助选材、读懂和建立稳定频率 |
| 已有稳定原版阅读习惯 | 次优先 | 需要更深内容，普通分级短文价值可能不足 |
| 基础明显不足，需要逐句教学 | 暂缓 | 自动工具可能无法独立解决，不能承诺无需任何辅导 |
| 初三、高三，只接受短期明确提分 | 暂缓 | 产品承诺与时间安排不匹配 |
| 高一，愿意持续拓展阅读 | 下一批单独验证 | 重新测试篇长、题材、能力任务和付费意愿 |

“家长省心”指减少选材、讲解和批改，不承诺孩子完全不用提醒。家长的合理角色是协商时间、提供设备、偶尔听孩子分享。

## 2. 相比 Achieve3000，六个核心改动

这里比较的是其分层阅读与测评机制如何适配家庭，不将项目旧文中“学生必然不满”“家长账号没人用”等概括视作已核实的普遍事实。

| 环节 | 纯 C 端改法 | 要验证的结果 |
| --- | --- | --- |
| 首次使用 | 先选兴趣、完成一篇短阅读，再逐步校准难度 | 孩子在首次使用中获得“我读懂了”的体验 |
| 内容组织 | 用连续主题和系列故事组织阅读，每次给 2—3 个选择 | 愿意主动选择下一篇，而非只领取签到奖励 |
| 阅读流程 | 大部分时间留给阅读，少量问题检查理解，每周一次较完整表达 | 减少题量后，独立理解表现仍能改善 |
| 难度调整 | 小步调节，先减少帮助；不同时增加篇长、词汇和推断难度 | 读得好后，完成时间与挫败感没有明显上升 |
| 家长反馈 | 每周一份简短报告，包含原始作品、证据和下一步 | 家长理解具体收获，监督和争执减少 |
| 付费与运营 | 完整试读后按月购买，以实际使用和主动续费检验价值 | 付费孩子仍在读，续费不依赖高强度人工催促 |

外研阅读家庭版已经提供分级阅读和定级测试，ReadTheory 也有自适应阅读及免费方案。因此“测等级＋推文章＋做题”不足以单独成为收费理由；竞品信息只证明功能存在，不证明其在中国家庭中的实际可用性或效果。[外研社产品介绍](https://www.fltrp.com/c/2021-10-28/507306.shtml)、[ReadTheory 产品页](https://readtheory.org/homepage/)、[ReadTheory 方案说明](https://help.readtheory.org/what-is-readtheory-premium)

## 3. 孩子为什么愿意回来：内容和完成感先于打卡

### 3.1 把阅读组织成有进展的系列

初期做六个主题系列，每个系列四篇，例如动物认知、体育与科学、科技与生活、人物选择、悬疑故事、人与环境。每篇解决一个完整问题，下一篇推进一个相关问题；允许换主题，不强迫先读完全部前置内容。

例如“推荐算法为什么总能猜中你？”系列可以依次讨论：平台看到哪些行为、推荐何时出错、为什么不同人看到不同内容、怎样给自己增加选择。内容应经编辑查证，不能为了追热点牺牲事实准确性。

**C 端没有全班同读一个主题的必要。** 先按兴趣和年龄选择，再匹配语言与理解难度；首版只为重点文章制作三档版本，避免把大量成本花在没人愿意读的选题上。题材成熟度与语言难度分开标注。

### 3.2 每周形成清楚的节奏

- 第一次：读一篇感兴趣的文章，回答少量理解问题，解决一个疑问。
- 第二次：读同主题的另一角度，比较两条信息，选出支持自己判断的证据。
- 第三次：读一篇新材料，完成一段短表达，生成自己的主题作品页。

这只是默认安排，孩子可以换主题、换时间。系统到完成点就结束，不以无限下拉增加使用时长。忙碌时可以只读收藏的文章，但该行为单列为“阅读”，不自动记成一次完整能力练习。

### 3.3 提供可恢复的习惯机制

目标按周设置，漏读后从当前内容继续，不清零累计成果，不补罚任务。奖励主要是看懂更复杂的问题、完成一个系列和积累自己的观点作品。

初期不做公开排名、随机抽奖和陌生人社交。可让孩子自愿向家长展示一张观点卡，但展示不绑定奖励或付费优惠。孩子可以表达不同意见，系统评价的是证据和推理，而不是观点是否迎合家长。

## 4. 一次完整体验应当长什么样

首开由家长完成必要同意与账户设置，孩子选择两个感兴趣的主题。用第一次试读作粗分层，明确推荐可能不准，允许随时选择“太难”“太简单”。经过三次阅读再调整，不把几分钟试读包装成权威能力测评。

| 时间建议 | 孩子看到的内容 | 设计目的 |
| --- | --- | --- |
| 约 1 分钟 | 2—3 个标题和一句问题，自选一篇 | 产生自己的阅读目标 |
| 约 7—9 分钟 | 正文、按需词义和句子帮助 | 保留真实阅读，而非让解说替代阅读 |
| 约 2 分钟 | 2—3 个关键理解问题，其中至少一个要求找证据 | 识别是否理解，并给具体反馈 |
| 约 2—3 分钟 | 简短反思；每周一次完成较完整的短答 | 将阅读转化为自己的表达 |

篇幅随实测速度调整，12—15 分钟不是强制倒计时。短答和测评有时需要额外时间，要明确预告，不隐藏任务负担。

**反馈示例（原创设计示意，非真实学生记录）：** 原文分别描述了一次实验和研究者的推测。学生说“这证明所有动物都有同样的能力”。系统先提示“找一找，实验研究了哪些动物”，再说明“这个实验支持对受测动物的判断，还不能推出所有动物”。让孩子修订结论，而非只给一个低分。

自动反馈先在已审核的证据和评分规准中选择；生成式解释必须能指向原文。低置信度时提示“这题暂不评分”，提供编辑解释和问题反馈入口。初期人工负责内容审校和错误处理，不默认逐条批改全体用户短答。

语言支持与测量分开：使用翻译、朗读或提示可以帮助学习，但报告要区分“借助支持完成”和“独立完成”。不能把听懂或看译文后的正确率当成独立英文阅读能力，也不需要用惩罚来阻止孩子求助。

## 5. 家长为什么付费和续费

购买前展示真实试读流程、适合谁、所需时间、内容范围和反馈样例。家长与孩子各完成一次价值体验：孩子读完一篇；家长看到这次阅读中的一条具体理解证据。正常反馈完整展示，不在错题解释中间设置付费墙。

每周报告控制在约一分钟可读完，内容包括：

1. 本周读了什么、完成几次，哪些借助了支持。
2. 一个具体收获，例如“本次能从第二段找出支持判断的句子”，附原作答；没有纵向证据时不写“能力提升”。
3. 一个仍需练习的问题，例如“容易把推测当成事实”。
4. 下一周安排，以及一个可选的家庭讨论问题。

孩子提前知道家长能看到完成记录和约定的学习作品；私人草稿默认不公开。家长端不提供逐分钟监控，不把低分立即推送成告警。

每四周安排未读过、难度可比的材料，展示独立理解表现和作品变化，并说明样本有限。阅读量、完成率、能力证据分别展示：读得更多不自动等于读得更好，等级上涨也不等于校内提分。

**续费理由应当有三项证据：孩子仍在使用、确有阅读收获、家长承担的教学劳动较少。** 若只有家长满意而孩子长期闲置，视为产品问题，不靠提醒家长“已经花钱了”维持续费。

## 6. 语文与英语：共享主题，分别解决问题

建议先把英语做成完整付费产品，语文先以少量独立样章验证需求。若用户确实要求双科，允许选择英语、语文或混合计划，混合计划仍是每周三次，不翻倍加量。

| 项目 | 英语设计 | 语文设计 |
| --- | --- | --- |
| 主要帮助 | 词句理解、信息提取、篇章与推断 | 概括、证据、表达效果、多文本整合 |
| 分层 | 同主题三档文本，逐渐减少语言支持 | 原文保留，调整注释、问题和表达要求 |
| 每周输出 | 用英文简短说明判断及理由，必要时分步搭建 | 用中文论述观点、比较文本或解释表达效果 |
| 文学内容 | 适当加入连续故事和人物选择 | 保留文学语言，允许多种有依据的解读 |
| 进展报告 | 语言障碍与理解能力分开描述 | 信息、推理、表达等分别呈现 |

同一问题可以设计中英文不同材料，形成两次独立阅读；不要把中文译文先给孩子读完，再将英文答对计作成长。也不要将语文等同于英文内容翻译。语文课标本身包括文学、思辨和整本书等不同任务，后续还应发展长文本阅读，不能长期停在碎片化短文。[教育部语文课标解读](https://www.moe.gov.cn/fbh/live/2022/54382/zjwz/202204/t20220421_620107.html)

## 7. 价格、获客与服务成本一起设计

### 7.1 先按月验证，不急着卖年卡

初期只设一个清楚的方案：免费体验三次完整阅读；之后测试 **49 元／28 天／单科**，含约十二次推荐阅读、主题库、支持工具、反馈和周报。价格只是实验假设，不是已验证的市场接受价。应醒目标注“28 天”，不能让用户误以为是自然月。

首轮采用手动续购，支持清楚的停止与退款入口。先观察一次真实续购，再考虑长期套餐；不把自动扣款率作为主动续费意愿。若未来启用自动续费，需落实服务前及扣费前的显著提醒等要求。[消费者权益保护法实施条例](https://app.www.gov.cn/govdata/gov/202403/19/513111/article.html)

不用低价产品承诺每天真人陪读。假设人工成本每小时 100 元，每个孩子每周只服务 10 分钟，四周也要约 66.67 元，已经高于上述售价。产品是否需要这种人工投入，应在试验中直接检验。

### 7.2 用保守的贡献计算约束获客

以下为简化现金贡献假设，未扣固定研发、编辑团队、管理成本及税费；实际支付渠道费率和版权合同可能不同。

| 每位用户每个 28 天周期 | 金额假设 |
| --- | ---: |
| 支付金额 | 49.00 元 |
| 预计退款损失，按支付额 5% | 2.45 元 |
| 支付与渠道费，按支付额 2% | 0.98 元 |
| 模型与云用量 | 3.00 元 |
| 内容按量授权等 | 3.00 元 |
| 客服及人工处理 | 5.00 元 |
| 获客前贡献 | **34.57 元** |

假设一批初购用户第二周期还有 65% 购买，第三周期还有 55% 购买，这两个比例都以最初付费人数为分母，则前三周期每名初购用户预计贡献为：34.57 ×（1＋0.65＋0.55）＝**76.05 元**。两个留存率尚无实测依据，这也不是终身价值。

若获得一名实际付费用户花费 90 元，前三周期尚未回本；花费 60 元，扣获客后仅余约 16.05 元，仍需承担固定成本。测试阶段可暂将混合获客成本 60 元作为观察线，之后用真实队列贡献调整，不能视为已具备利润空间。

免费试用的云、内容、客服费用及内容营销人员工时，都要计入获客或相应成本。内容自然传播也有成本；归因时按新付费家庭去重，不把一次阅读点击算成获客成功。

### 7.3 纯 C 端的获客顺序

先通过自有受众和自愿招募找到家庭，分别访谈家长与孩子；随后在允许的经营与推广范围内测试产品样章展示、用户主动推荐及内容搜索入口。每个来源记录试读、完成、购买、退款与下一期购买，找到能带来持续读者的渠道。

对外展示可以围绕“实际怎么读、如何处理读不懂、报告到底有什么”展开，所有演示标明是样例还是真实授权记录。避免依靠焦虑、排名或无法证明的提分承诺促单。

**渠道方案有前提：具体产品形态允许如此经营和推广。** 面向中小学生的校外培训广告受到专门管控，不能通过软文、达人分享或改名“阅读会员”绕开。这里不默认可以购买信息流广告，也不将自然内容营销认定为当然豁免。[校外培训广告管控通知](https://www.cac.gov.cn/2021-11/11/c_1638226444835143.htm)

## 8. 首版范围与八周验证

先做移动网页或小程序中的单一入口：选题、阅读、按需支持、理解反馈、个人作品和家长周报。学生阅读界面优先适配平板，手机可用；家长在手机查看报告。暂不开发原生多端 App、教师后台、班级系统或全量自由聊天。

英语内容首版为六个系列 × 四篇 × 三档＝72 个审核版本，另有独立复测材料。三次试读可使用主题库内容，但不能消耗复测题。内容库不是课程顺序锁定：既保证低选择成本，也让孩子能换主题。

| 时间 | 工作 | 主要产出 |
| --- | --- | --- |
| 第 1—2 周 | 访谈约 20 组家长与孩子，观察 10 组首次使用；明确内容版权、数据及经营分类 | 试读样章、一个完整流程、可解释的付费方案 |
| 第 3—4 周 | 招募约 100—200 个家庭体验；在可收费前提下收取真实购买款 | 首次完成、后续阅读、首次购买及退款记录 |
| 第 5—8 周 | 继续使用，观察各队列首次 28 天续购和独立复测 | 持续使用、家长投入、首次续购及初步效果信号 |

不为获得漂亮留存额外加每日真人督学；运营提供的任何提醒、讲解和催促都记录时长及成本。八周包含准备和分批入组，部分家庭尚未到续购日，必须排除未到期者；第二次续购及长期效果需延长观察。

产品的核心使用指标建议是“每周在至少两个不同日期完成有效阅读的付费学生比例”，同时观察下一周期续购和独立理解表现。有效阅读指到达正文结束、提交约定的证据任务及反思；不以高正确率作为完成门槛，避免把需要帮助的学生排除。该指标也不声称能完全识别代做或作弊。

建议预设以下门槛，作为团队决策假设而非行业基准：

| 指标 | 口径与建议观察线 |
| --- | --- |
| 首次价值 | 完成首次阅读的孩子／真正进入试读正文的孩子 ≥70%，另报邀请到进入的损耗 |
| 四周使用 | 已满四周的初购队列中，第 4 周至少两天有效阅读者 ≥50% |
| 首次续购 | 到期后七天内实际续购／已到期且过完七天观察窗的全部初购家庭 ≥50%；退款者保留在初购分母 |
| 家长负担 | 每周讲解、批改、催促总投入的中位数 ≤15 分钟，同时报告高负担家庭占比 |
| 获客 | 暂以每名新付费家庭混合获客成本 ≤60 元观察，核算真实贡献后再定扩张线 |
| 学习 | 未见材料表现有正向信号，错误反馈可纠正；小样本前后测不能证明因果提分 |

满意度分别问孩子和家长。至少记录孩子是否愿意继续、家长是否认为值得、家庭实际监督时间；不能通过用户一直在线推断孩子喜欢阅读。前后测缺测与流失单独报告，不只统计完成者。

如果孩子只在催促下使用，应先改内容、难度或流程；如果家长认可但不续购，要区分价格、收获、时间冲突及退款问题；如果只有高成本人工服务才能留住，需重新评估服务产品及其经营条件，不能继续按低价软件会员模型计算。

## 9. 纯 C 端需要落实的边界

本次用户排除的是 B 端业务，并未排除经营政策。语文学科和英语阅读如果以系统教学、能力训练和成绩提升为实际内容，仍需按真实功能核查分类；指南已把人工智能教师纳入鉴别，取消真人或弱化“提分”文案不自动改变性质。[教育部分类鉴别说明](https://www.moe.gov.cn/jyb_xwfb/gzdt_gzdt/s5987/202111/t20211112_579395.html)

因此，阅读内容会员和学习工具是本方案的产品方向，不是法律豁免结论。明确经营主体和适用资质后，再启动收费、招生性质活动及推广；如核心功能被认定为学科培训且无法满足经营要求，应停止该收费方案，而非换包装。

未成年人账户、家长可见信息、版权改写范围、AI 输出及标识沿用上一份报告中已核查的要求，具体实现仍需逐项落实。此次只完成方案与测算，没有对外发送消息、收取费用或开发上线产品。

**当前最值得验证的 C 端产品，是一份孩子愿意连续读、家长看得懂价值的阅读会员。先证明“愿意读、确有收获、会再买”，再增加科目、年级和功能。**
