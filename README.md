## 说明

- 这是一组**内部工作稿**，公开仅为便于评审。文中的定价、内容量、各项指标均为**待验证建议，不是承诺**。
- 02B、03、09 由并行会话产出，与其余各篇在个别判断上存在分歧（例如首批客户应否走学校渠道），分歧点在 04 开头写明，未作统一。
- 名著与古诗文为公有领域作品，原文取自维基文库，逐字未改；原创选文版权自持。
- 非连续性文本中的数据为教学用虚构材料，不得作为事实引用。
